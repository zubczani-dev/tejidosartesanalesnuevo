Tienda de Tejidos a Crochet

Este proyecto es una página web para mostrar y vender tejidos artesanales realizados por la inspiración y dedicación de una apasionante tejedora.
 

 Proyecto Final:
 Zubczuk, Ana Paula.

 Objetivos: 
1)	Desarrollar un sitio web que conecte a la vendedora con los consumidores para optimizar la relación entre la oferta y la demanda.
2)	Diseñar un espacio digital atractivo e interactivo que permita a los clientes expresar sus ideas, y recibir respuestas con el fin de mejorar su experiencia de búsqueda y compra.
3)	Incrementar las ventas de productos artesanales mediante la innovación tecnológica en el comercio electrónico para alcanzar a la mayor cantidad de clientes posibles.

Objetivos específicos:

1)	Diseñar y crear el sitio web de tejidos a crochet en un tiempo de un mes. 
2)	Contar con un espacio en el cual se pueda ilustrar la historia e inicio de este emprendimiento.
3)	Incorporar e implementar un catálogo, el cual posea 30 productos artesanales diversos clasificados por tipo.
4)	Incrementar un espacio donde los usuarios puedan añadir comentarios y consultas para que la vendedora pueda estar al tanto de ciertas dudas o consultas. 
5)	Lograr ser un espacio atractivo y que permita incrementar las ventas, a través de un servicio de pago cómodo, como transferencias bancarias, etc.
